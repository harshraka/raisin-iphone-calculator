🧮 Raisin Challan Calculator

Private by design · Calculations stay on this iPhone

1. Add challan photo (optional)

The image preview stays in this page and is not uploaded. This app does not perform cloud OCR. On iPhone, open the photo in Photos and use Live Text to copy handwritten/printed text where supported, then enter or correct the values below.

2. Read text on iPhone (private)

This Home Screen web app cannot directly call Apple's private Vision/Live Text API. To keep recognition on-device, open the photo in Photos, use Live Text to select/copy the register text, then paste it here. This parser runs on this iPhone and makes editable draft rows; verify everything against the image.

Nothing is uploaded. Parsing is done locally in this page.

3. Lot entries

Enter one lot per card. Fractions are comma-separated: 63/15 means 63 boxes at 15 kg each. A single blank numerator such as 1/12.5, /15 means the remaining boxes. Multiple blank numerators are flagged, never guessed. For HCR-55/50, enter original mark exactly, identity HCR-55, actual boxes 50.

Entries are not saved automatically. Tap Save to keep them on this device.

Privacy & limitations

No account, API key, analytics, external AI, or data-upload code. After the app has been installed from its website once, its files can work offline. Each iPhone stores its own entries separately; saved entries do not automatically sync between phones. OCR is manual via iPhone Live Text, so check every value.
